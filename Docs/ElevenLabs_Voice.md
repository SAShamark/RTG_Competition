# Flame & Blame — репліки для ElevenLabs v4

Це погоджені репліки з DialogueVoice.md, згруповані за персонажами. Кожен кодовий блок — окремий кліп: копіюй лише текст усередині, включно з тегом у квадратних дужках. Ідентифікатор над блоком використовуй для назви файлу. Теги — запропонована акторська подача, не новий сценарій.

Вибери одного голосового актора на персонажа й зберігай його для всіх реплік. Eleven v4 підтримує українську й теги емоцій; результат залежить від голосу. Якщо тег вимовляється вголос або звучить неприродно, спробуй простіший тег чи прибери його. Генеруй кожну репліку окремо, щоб отримати окремі файли для Unity.

Джерела: [аудіотеги ElevenLabs](https://elevenlabs.io/docs/help-center/product/core-capabilities/text-to-speech/how-do-audio-tags-work-with-eleven-v3-and-v4), [вибір голосів](https://elevenlabs.io/docs/eleven-creative/voices/voice-library/), [підтримка української](https://elevenlabs.io/docs/overview/models).

## Напарник

Характер: чоловік 30–45 років, природний український, енергійний, дружній, трохи хриплуватий; сарказм без агресії. Кандидат для проби: Anton — Friendly and Warm Storyteller; також Alex Nekrasov — Confident and Clear. Порівняти на P01 і P06, слухати українську вимову.

### P01
```text
[shouts] Ти шо, пожежу обганяєш?! Гальмуй, Махмуд!
```

### P02
```text
[urgent] Махмуде, будинок номер дванадцять! Там люди — бігом!
```

### P03
```text
Тут замок, візьми лом у відсіку зі спорядженням.
```

### P04
```text
[surprised] Це... він що, котів рятував?! [urgent] Заходь! Вогонь біля сходів — вогнегасник у червоному щитку.
```

### P05
```text
[encouraging] Бери його — і до вогню!
```

### P06
```text
[sarcastically] Махмуд, ліфт під час пожежі? Ти серйозно?
```

### P07
```text
[urgent] Прохід чистий! Підіймайся, там ще люди!
```

### P08
```text
[urgent] Бабусю прийняв, на третьому поверсі хтось лається, бігом туди!
```

### P09
```text
[urgent] Є другий! Усі на вулиці — Махмуде, виходь звідти!
```

### P10
```text
[amazed] Та ти супергерой!
```

## Махмуд

Характер: чоловік 25–40 років, український голос середнього або нижчого регістру, впевнений, але трохи розгублений, природний сухий гумор. Кандидати: Alex Nekrasov — Confident and Clear або Artem Klopotenko — Low, Rich and Deep. Прослухай M02 і M07: важливі виразність та відмінність від напарника.

### M01
```text
[urgent] Бабусю, пожежна! Виходимо, швидко!
```

### M02
```text
[exasperated] Які документи, бабусю? Будинок горить!
```

### M03
```text
Добре, де вони?
```

### M04
```text
[reassuring] Тримайтеся міцніше. [playful] Підемо... коротким шляхом.
```

### M05
```text
[urgent] Це газ горить! Де його перекрити?
```

### M06
```text
[reassuring] Зараз я тебе врятую!
```

### M07
```text
[startled] Зараз рвоне! Я у вікно!
```

## Бабуся

Характер: літня українка, впевнений жвавий голос із теплою хриплинкою; уперта, але не карикатурна. У Voice Library шукай Ukrainian + Female + Old + Characters, тестуй G02 і G07. Конкретний український літній голос перевірити прослуховуванням: надійного кандидата за назвою не знайдено.

### G02

```

### G03

```

## Дядько

Характер: чоловік 45–65 років, гучний, хрипкуватий, самовпевнений; комізм через серйозність, без надмірного крику. Кандидат для проби: Artem Klopotenko — Low, Rich and Deep; якщо цей голос обрано для Махмуда, пошукай інший український грубуватий характерний голос. Перевірити U01 і U02.

```

### U02

```

### U03
```text

```

## Вибір і перевірка голосів

1. У Voices → Explore обери мову Ukrainian, за потреби фільтри Characters / Conversational, стать і вік. [Довідка ElevenLabs](https://elevenlabs.io/docs/eleven-creative/voices/voice-library/).
2. Офіційна [українська сторінка ElevenLabs](https://elevenlabs.io/text-to-speech/ukrainian) перелічує Alex Nekrasov, Anton, Artem Klopotenko, Leonid Drapei та Vira. Це кандидати, а не прослухані або гарантовано придатні голоси; доступність може залежати від акаунта.
3. Для кожного персонажа спершу зроби дві проби: спокійну репліку та емоційну. Перевір наголоси, ім'я Махмуд, природність української та різницю між персонажами.
4. Якщо готового голосу бабусі немає, спробуй Voice Design: «An elderly Ukrainian woman with a naturally raspy, warm, spirited voice, clear native Ukrainian pronunciation, conversational and stubborn, suitable for a light comedy game, no exaggerated caricature.» Для інших персонажів аналогічно використовуй описи з розділів вище.
5. Почни з поточного середнього значення Stability на скриншоті. Якщо подача одноманітна, змісти трохи до Creative; якщо занадто нестабільна — до Robust. Значення — старт для експерименту, не гарантія результату.
6. Зберігай кліпи за ID, наприклад P01.wav, M01.wav. Довжину й паузи перевір у сцені; не накладай радіоефект на вихідні файли, якщо його буде додано в Unity.

Примітка: фінальний список не містить непогоджених радіопідказок та реакцій на картини. У DialogueSequence.md вони наведені окремо для перевірки перед додатковою озвучкою.
