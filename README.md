# Flame & Blame

Гра від першої особи про пожежника: потрапити в палаючий будинок, загасити вогонь, знайти та вивести мешканців і перекрити газ, поки не стало пізно. Зроблено на Unity 6 (URP) як тестове завдання.

## Завантажити

**[Завантажити білд для Windows (zip, 112 МБ)](https://github.com/SAShamark/RTG_Competition/releases/latest/download/Flame.and.blame.Build.zip)**

Розпакуйте архів і запустіть `.exe`. Усі версії — на сторінці [релізів](https://github.com/SAShamark/RTG_Competition/releases).

## Керування (VR, гілка `feature/VR_test`)

Гра працює лише у VR: Meta Quest через Quest Link / Air Link або будь-який шолом OpenXR (SteamVR). Перед запуском підключіть шолом.

| Дія | Як |
| --- | --- |
| Рух / біг | Лівий стік / натиснути лівий стік |
| Поворот | Правий стік: снеп 30/45/90° або плавний (Налаштування) |
| Стрибок | A (або натиснути правий стік) |
| Взяти предмет, підняти людину | Піднести руку до об'єкта (він засвітиться) й затиснути хват |
| Притягнути предмет здалеку | Наведи руку на предмет — він засвітиться і клацне в контролері; затисни хват і смикни руку до себе чи вгору — предмет прилетить у долоню (тримай хват). Працює й для маховиків, ручок, грошей |
| Передати з руки в руку | Схопити предмет другою рукою; або тримати двома руками й відпустити першу |
| Двері | Схопити хватом і тягнути — двері йдуть за рукою; короткий хват без руху відчиняє/зачиняє |
| Вентиль | Схопити колесо й крутити кистю (кожні 180° — оберт); B — оберт назад |
| Тримати предмет | Тримати хват затиснутим. Відпущений інструмент сам іде на пояс (у кобуру поруч або першу вільну); речі без місця на поясі кидаються зі швидкістю руки |
| Натиснути кнопку (ліфт) | Торкнутися пальцем |
| Удар сокирою | Справжній замах: удар зараховується, коли лезо на швидкості влучає в поверхню. Лівою рукою можна взятися за держак — дворучний удар сильніший і менше втомлює |
| Вогнегасник / шланг | Курок руки, що тримає, — розпилювати; струмінь іде туди, куди дивиться сопло. Лівою рукою можна взятися за сопло й цілитися нею |
| Інвентар | Пояс із 3 кобурами (ліве стегно, перед, праве стегно): відпусти хват біля кобури — сховати, затисни хват біля кобури — взяти |
| Поставити людину | B |
| Рація (підказка) | Схопити рацію на лівому плечі (або Y) |
| Пропустити катсцену / далі в діалозі | Утримувати A або курок |
| Пауза | Кнопка меню або X (лівий контролер) |
| Меню | Лазер правого контролера, клік — курок |
| Сейф | Відсунь картину — поруч записка з кодом. Набери 4 цифри пальцем на клавіатурі сейфа (C — стерти, OK — перевірити), потім поверни ручку |
| Двері комори | Схопи ключ у замку й поверни кисть. Або збий замок сокирою |
| Поточна ціль | Глянути на годинник на лівому зап'ясті |

Ціль і кількість врятованих — на годиннику на лівому зап'ясті, підказки — біля об'єктів, діалоги йдуть від першої особи. Комфорт (поворот, віньєтка під час руху, рух за напрямком голови чи руки) — у Налаштуваннях. Решта HUD показується на «візорі» перед очима, меню й головоломки — на панелі, вступний ролик — на великому екрані, а решта сцен (дядько з котами, кидок на батут, вибух газу, стрибок, фінал) відбувається просто навколо гравця; переходи — через плавне затемнення. Руки фізичні: не проходять крізь стіни, пальці згинаються від хвату й курка, контролери вібрують при ударах і розпиленні.

## Про виконання тестового завдання та використання ШІ

Спочатку я проаналізував відео Flame and Blame та розглянув кілька ідей для гри: механіки з падаючими деревами, батути й порятунок людей з будинку. Зрештою зупинився на останньому варіанті. Я продумав основні взаємодії та діалоги, обговорював ідеї з ChatGPT, а він фіксував узгоджені нотатки.

Для прикладу архітектури та стилю коду я надав Claude Code свої проєкти. Прототип ми спочатку створювали на примітивах. Більшість коду написав Claude Code під моїм керівництвом, а потрібного результату ми досягали через численні ітерації. У проєкті також використано Cinemachine.

Асети я добирав самостійно, а ChatGPT допомагав шукати безкоштовні ресурси, генерувати стилістичні референси зі скріншотів і текстури для ефектів. На основі цих матеріалів Claude Code будував оточення та створював ефекти, які я коригував.

Звуки й музику я також підбирав сам, а частину аудіо генерував на основі текстів персонажів. Наприкінці я поверхнево відрефакторив код.
