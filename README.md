# Flame & Blame

Гра від першої особи про пожежника: потрапити в палаючий будинок, загасити вогонь, знайти та вивести мешканців і перекрити газ, поки не стало пізно. Зроблено на Unity 6 (URP) як тестове завдання.

## Завантажити

**[Завантажити білд для Windows (zip, 112 МБ)](https://github.com/SAShamark/RTG_Competition/releases/latest/download/Flame.and.blame.Build.zip)**

Розпакуйте архів і запустіть `.exe`. Усі версії — на сторінці [релізів](https://github.com/SAShamark/RTG_Competition/releases).

## Про виконання тестового завдання та використання ШІ

Спочатку я проаналізував відео Flame and Blame та розглянув кілька ідей для гри: механіки з падаючими деревами, батути й порятунок людей з будинку. Зрештою зупинився на останньому варіанті. Я продумав основні взаємодії та діалоги, обговорював ідеї з ChatGPT, а він фіксував узгоджені нотатки.

Для прикладу архітектури та стилю коду я надав Claude Code свої проєкти. Прототип ми спочатку створювали на примітивах. Більшість коду написав Claude Code під моїм керівництвом, а потрібного результату ми досягали через численні ітерації. У проєкті також використано Cinemachine.

Асети я добирав самостійно, а ChatGPT допомагав шукати безкоштовні ресурси, генерувати стилістичні референси зі скріншотів і текстури для ефектів. На основі цих матеріалів Claude Code будував оточення та створював ефекти, які я коригував.

Звуки й музику я також підбирав сам, а частину аудіо генерував на основі текстів персонажів. Наприкінці я поверхнево відрефакторив код.
